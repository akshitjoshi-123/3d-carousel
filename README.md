# 3D Carousel

A free, lightweight **3D curved carousel** built with pure **HTML, CSS and JavaScript**. No libraries or dependencies.

**[Live demo](https://akshitjoshi-123.github.io/3d-carousel/)**

## Features
- 3D perspective carousel with smooth easing
- Drag, swipe, click, arrow-key and button navigation
- Pagination dots
- Responsive and mobile friendly
- Accessible (ARIA labels, keyboard focus, reduced-motion support)

## Usage
Open `index.html` in any browser, or host it with GitHub Pages.

Edit the `cardData` array in `index.html` to change the slides.
